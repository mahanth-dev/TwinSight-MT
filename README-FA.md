# TwinSight · محصول MT

وب‌اپ مستقل برای کاتالوگ آساره اسپرت و تطبیق تصویری با کالای رقیب.

## اجرا با Docker

پوشهٔ `mt-tahlil` را هر جا بردی، داخلش:

```bash
docker-compose up --build
```

اولین بار با `--build`. آدرس: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

دیتابیس، عکس کاتالوگ و کش رقیب داخل `data/` است و با volume می‌ماند.

بدون Docker:

```bash
./start.sh
```

## کراول رقیب

محصول خودمان مرجع است: از نام و خانوادهٔ کالا چند عبارت جستجو ساخته می‌شود،
نتایج رقیب گرفته می‌شود، عکسشان دانلود و اثرانگشت تصویری‌اش با عکس‌های خودمان
مقایسه می‌شود.

دو مسیر برای رقیب‌ها وجود دارد:

- فروشگاه‌هایی که API دارند (ووکامرس Store API): مستقیم JSON گرفته می‌شود.
- فروشگاه‌هایی که API نمی‌دهند: صفحهٔ جستجویشان مثل یک بازدیدکنندهٔ معمولی
  خوانده می‌شود و کارت محصول‌ها (لینک، عکس، عنوان، قیمت) از HTML بیرون کشیده
  می‌شود. فهرست این فروشگاه‌ها در `tahlil/matching/html_shop.py` است.

```bash
# همهٔ محصولات
python manage.py crawl_rivals --limit 500 --workers 8

# فقط یک خانواده یا یک محصول
python manage.py crawl_rivals --family yoga --limit 20
python manage.py crawl_rivals --id 2438

# فقط یک فروشگاه / بدون فروشگاه‌های HTML
python manage.py crawl_rivals --shop anik.ir --limit 10
python manage.py crawl_rivals --no-html --limit 10
```

## قانون تطبیق

عکسِ شبیه به‌تنهایی هیچ‌وقت حکم قطعی نمی‌دهد، چون عکس استودیویی دو کالای
بی‌ربط هم شبیه هم در می‌آید. برای `match` هم عکس باید نزدیک باشد و هم عنوان
تأیید کند، و اگر دو عنوان مدل یا سایز متفاوتی را نام ببرند (ASTROX 88D در
مقابل ASTROX 77، یا ۱ لیتری در مقابل ۹۰۰ میلی) حکم قطعی داده نمی‌شود.

اگر قانون عوض شد، لازم نیست دوباره کراول کنی:

```bash
python manage.py rescore_rivals               # فقط بازبینی
python manage.py rescore_rivals --drop-rejected  # ردشده‌ها را هم پاک کن
```
